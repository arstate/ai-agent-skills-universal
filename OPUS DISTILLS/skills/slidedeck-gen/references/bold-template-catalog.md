# Bold Template Catalog — 34 Design Archetypes
> Distilled from `zarazhangrui/frontend-slides` (`bold-template-pack`) for `slidedeck-gen`.
> All templates adhere to the 16:9 fixed-stage layout model (`1920x1080`), zero-margin vector PDF print CSS, and high-impact typographic discipline.

---

## Architecture & Layout Principles
- **Stage Model:** Exact `1920x1080` canvas with fluid responsive downscaling (`transform: scale(...)`).
- **Typography Standards:** Strict contrast hierarchy — Roman/grotesque headers, clean sans body, monospace chrome metadata. Zero illegible italic scripts on primary technical titles.
- **Surface Rhythm:** Alternating dark void (`#090A0F`, `#121214`, `#0E241B`) and paper surfaces (`#FAF7F2`, `#FFFFFF`) with single hot accents (`#FF5722`, `#3B82F6`, `#D4AF37`).
- **PDF Export:** Native zero-margin vector export via Chrome CDP with `-webkit-print-color-adjust: exact !important` on all slide layers.
