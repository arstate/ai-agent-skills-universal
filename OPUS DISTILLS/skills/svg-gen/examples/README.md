## 🛡️ Jaminan Kepatuhan 10-Gate

1. **Kanvas 16.0 Megapixels:** Seluruh aset menggunakan `width="4000" height="4000" viewBox="0 0 4000 4000"`.
2. **100% Closed Paths (`Z`):** Setiap elemen `<path>` berakhiran `Z`, `0 Open Paths`.
3. **0% Live Strokes:** Garis chip kartu, tanda centang, simbol mata uang `$`, dan panah grafik berupa kurva poligon tertutup (`fill-rule="evenodd"`).
4. **0% Alpha Opacity & 0% Filter:** Menjamin `0 cairo_image` saat diekspor ke format `.EPS`.
5. **Background Transparan Murni:** Tanpa `<rect>` putih dan tanpa garis bantu tabel putus-putus, sehingga memicu badge otomatis **"Transparent PNG available"** di Adobe Stock.
6. **Zero-Text Rule:** Tidak ada tag `<text>` atau `<tspan>`.
7. **Bebas Kata Terlarang "AI":** Metadata bersih dari kata `"AI"`, `"Artificial Intelligence"`, dan `"Midjourney"`.
