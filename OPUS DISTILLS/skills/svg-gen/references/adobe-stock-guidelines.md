# Adobe Stock, Shutterstock & Freepik Vector Guidelines (10-Gate Standard)

## The 10 Iron Laws of Vector Construction

Every vector asset generated by `/svg-gen` must pass these 10 strict validation gates before export:

1. **100% 2D Flat Vector Murni (Zero 3D):**
   - No 3D extrusion, no metallic bevel/emboss, no fake blur drop shadows, no gradient mesh.
   - Use flat solid fills, solid cast shadows, or isometric 30° projection.

2. **Canvas Resolution $\ge 15.0\text{ Megapixels}$:**
   - Square (1:1): `width="4000" height="4000" viewBox="0 0 4000 4000"` (16.0 MP) or `5000 x 5000` (25.0 MP).
   - Landscape (5:3 / 16:9): `width="5000" height="3000" viewBox="0 0 5000 3000"` (15.0 MP) or `6000 x 3375` (20.25 MP).

3. **100% Closed Compound Paths (`Z`) & Zero Live Strokes:**
   - Every shape element must be a closed path ending in `Z` (`<path d="... Z" />`).
   - 0 live strokes (`stroke="none"` or omitted). No `<line>` or `<polyline>`.
   - Hollow shapes must use compound paths (`fill-rule="evenodd"`).

4. **Zero Alpha Opacity & Zero Filter Raster (`cairo_image = 0`):**
   - 0 `opacity`, `fill-opacity`, `stroke-opacity`, `stop-opacity`.
   - 0 `<filter>`, `<feGaussianBlur>`, `<feDropShadow>`, `<image>`, or `<foreignObject>`.
   - Simulate shading using adjacent 100% solid Hex swatches (Split-Tone Shading).

5. **Zero-Text Rule for Icons & Characters (`<text> = 0`):**
   - No typography or text labels under icons.
   - Currency symbols (`$`, `€`, `₿`), arrows, checkmarks must be drawn as pure closed paths (`<path d="... Z" />`).

6. **Auto-Fit Browser Preview & Transparent Background on Icon Packs:**
   - Always include `style="max-width:100%;height:auto;display:block;background:#FFFFFF;"` on the root `<svg>`.
   - Omit the `<?xml ...?>` prolog to allow smooth live preview rendering in VS Code and web browsers.
   - For standalone icon packs, omit solid background rects in the production `.svg` so Adobe Stock grants the green "Transparent PNG available" badge.

7. **Semantic Grouping (1-Click Editing):**
   - Wrap each icon inside `<g id="icon-XX-descriptive-name">`.
   - Color paths separated for single-click recoloring in Adobe Illustrator.

8. **Blank Customizable Copy-Space:**
   - Badges, ribbons, and banners leave blank space in the center with 0 embedded text.

9. **Strict Naming & Metadata (SEO Engine):**
   - Title $\le 70$ characters (no keyword stuffing).
   - Filename $\le 30$ characters, lowercase snake_case.
   - 25–40 high-relevance keywords (first 10 weighted at 80% by Adobe Sensei).

10. **Two-Pass Generation Discipline:**
    - Pass 1: Clean & simple silhouette skeleton (`*_pass1_base.svg`).
    - Pass 2: Retouch with split-tone planar shading, specular crescent highlights, and sparkles (`*_pass2_final.svg`).
