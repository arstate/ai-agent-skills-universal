## 🎨 2. Master Formula Prompt Konsep AI (`/gen-img`)

Gunakan template prompt ini saat membuat konsep visual dengan `/gen-img`:

```text
/gen-img "flat 2d vector icon set, [NAMA_TOPIK], isolated on pure white background, corporate clean aesthetic, solid vibrant colors, sharp clean vector contours, bold outlines, zero 3d extrusion, zero bevel, zero shadows, zero gradients, zero text, zero typography, generous outer margins, wide spacing between elements" -r 1:1 -o "raw/[NAMA_ASET]_concept.jpg"
```

### Aturan Kunci Prompt AI Raster:
1. **Wajib Tambahkan:** `"flat 2d vector icon"`, `"zero 3d extrusion"`, `"zero text"`.
2. **Wajib Rasio 1:1 untuk Icon Set:** Mencegah ikon terpotong di tepi atas dan bawah kanvas.
3. **Outer Margin Guard:** Selalu sertakan `"generous outer margins"` agar objek tidak menempel ke tepi kanvas.
4. **Haram Menggunakan Kata "AI":** Jangan masukkan kata AI ke dalam judul output aset!
