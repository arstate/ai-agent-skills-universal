## 🏛️ 1. Filosofi Utama v6.0: Minimal Design × Materi Ads Berkualitas Tinggi

Masalah terbesar desain poster AI konvensional adalah **"Box Fatigue / Terlalu Rame"**: menumpuk banner kuning penuh di atas + puluhan kotak ber-border tebal (`3px` navy + hard shadow `6px`) dalam satu kanvas `1080×1440`. Hasilnya sempit, kaku, melelahkan mata, dan mengaburkan pesan utama.

Di **v6.0 Minimal High-Impact**, kita mengunci **6 Hukum Desain Minimalis Berkonversi Tinggi**:
1. **58%–65% Open Warm Cream (`#F7F4EC`) Negative Space:** Jangan bungkus seluruh headline di dalam kotak banner kuning penuh! Biarkan headline bernapas langsung di atas kanvas *Warm Cream* `#F7F4EC` (grid arsitektural tipis `36px` `#EAE5D9`), dan gunakan **HANYA 1 pill `#FFD60A` Yellow-Gold** tepat di belakang 2–3 kata kunci utama (contoh: `[Langsung Tayang.]`, `[Orderan.]`, atau `[Mulai 1.5 Juta]`).
2. **Maksimal 3–4 Container/Card di Seluruh Kanvas (`1080×1440`):** Dilarang membuat lebih dari 4 kotak ber-border dalam 1 poster! Ganti tumpukan kotak fitur dengan **Editorial Numbered Typography (`01`, `02`, `03`) + Garis Pemisah Tipis `1.5px` (`#DAD4C6`)** langsung di atas background cream.
3. **Batas Margin Luar `88px` Kiri-Kanan (`x = 88..992`, Lebar Aktif `w = 904px`):** Semua elemen utama (Header `y=56`, Headline `y=156`, Isi/Hero `y=436..1056`, Conversion Bar `y=1136..1296`, dan Footer `y=1340`) WAJIB rata kiri-kanan secara matematis di **`x = 88`** sampai **`x = 992`**.
4. **Materi Ads Tajam & Spesifik (Anti-Basa-Basi):** Minimalis bukan berarti miskin informasi! Tulis copywriting yang langsung menghantam angka dan hasil nyata:
   - Sebutkan metrik konkret: **`PageSpeed 98+ · LCP <1.2s`**, **`Pixel + Server CAPI Aktif`**, **`Auto-WA Checkout · 0% Komisi`**, **`Garansi 5 Hari Kerja`**.
   - Maksimal **2 baris pendek per poin** (`18px–19px` Medium `#334155`) agar mata audiens langsung menangkap nilai jual dalam **1,5 detik**.
5. **Dedicated `02_HERO_IMAGE_DROP_ZONE` + AI Photo Brief:** Sediakan panggung visual bersih (`448×620px` di kanan atau lingkaran matahari `#FFD60A` `Ø 400px` di tengah) dengan properti **`clipsContent = true`** tempat user bisa *drag-and-drop* foto model cutout / mockup HP secara manual, lengkap dengan **Brief AI / Panduan Foto** di chat.
6. **Sleek Single-Row Conversion Bar (`y = 1136..1296`, `w = 904, h = 160`):** Satu bar konversi Deep Navy (`#012969`, radius `24px`, shadow tegas `6px, 6px, #0D1321`) yang menyatukan **Anchor Harga di Kiri** (`Mulai Rp 1.500.000` + strikethrough harga normal presisi di tengah vertikal angka) dan **Tombol WA Hijau Emerald `#10B981` di Kanan** (`Konsultasi Gratis → WA: 0851-9659-8881`).

## ⚡ 6. Contoh Kode Eksekusi Langsung (`figma_execute` via `figma-bridge`)

Jalankan script di bawah ini pada tool `figma_execute` untuk membangun Poster Minimal Ad 1 (1080×1440) secara otomatis di Figma:

```javascript
(async () => {
  await Promise.all([
    figma.loadFontAsync({ family: "Inter", style: "Medium" }),
    figma.loadFontAsync({ family: "Inter", style: "Bold" }),
    figma.loadFontAsync({ family: "Inter", style: "Extra Bold" }),
    figma.loadFontAsync({ family: "Inter", style: "Black" })
  ]);

  const hex = (h) => {
    const c = h.replace('#', '');
    return {
      r: parseInt(c.substring(0, 2), 16) / 255,
      g: parseInt(c.substring(2, 4), 16) / 255,
      b: parseInt(c.substring(4, 6), 16) / 255
    };
  };

  const C = {
    CREAM: hex('#F7F4EC'),
    NAVY: hex('#012969'),
    INK: hex('#0D1321'),
    SLATE: hex('#334155'),
    LINE: hex('#DAD4C6'),
    YELLOW: hex('#FFD60A'),
    GOLD_TEXT: hex('#D97706'),
    CRIMSON: hex('#B3001B'),
    EMERALD: hex('#10B981'),
    WHITE: hex('#FFFFFF')
  };

  const hardShadow = (dx = 6, dy = 6) => [{
    type: 'DROP_SHADOW',
    color: { ...C.INK, a: 1 },
    offset: { x: dx, y: dy },
    radius: 0,
    spread: 0,
    visible: true,
    blendMode: 'NORMAL'
  }];

  const addText = (parent, text, x, y, size, style, color, width = null) => {
    const t = figma.createText();
    t.fontName = { family: "Inter", style };
    t.characters = text;
    t.fontSize = size;
    t.fills = [{ type: 'SOLID', color }];
    if (width) {
      t.textAutoResize = 'HEIGHT';
      t.resize(width, t.height);
    }
    t.x = x; t.y = y;
    parent.appendChild(t);
    return t;
  };

  const addRect = (parent, name, x, y, w, h, fill, radius = 0, strokeWidth = 0, withShadow = false) => {
    const r = figma.createRectangle();
    r.name = name;
    r.x = x; r.y = y;
    r.resize(w, h);
    r.cornerRadius = radius;
    r.fills = [{ type: 'SOLID', color: fill }];
    if (strokeWidth > 0) {
      r.strokes = [{ type: 'SOLID', color: C.INK }];
      r.strokeWeight = strokeWidth;
    }
    if (withShadow) r.effects = hardShadow(6, 6);
    parent.appendChild(r);
    return r;
  };

  const root = figma.createFrame();
  root.name = "POSTER_STYLE_A_MINIMAL_HIGH_IMPACT_V6";
  root.resize(1080, 1440);
  root.fills = [{ type: 'SOLID', color: C.CREAM }];
  root.clipsContent = true;

  // Header (y = 56..122, x = 88..992)
  addRect(root, "Logo_Badge", 88, 56, 44, 44, C.NAVY, 11);
  addText(root, "D", 101, 63, 24, "Black", C.WHITE);
  addText(root, "DJadi", 144, 59, 30, "Black", C.NAVY);
  addText(root, "creative", 232, 61, 28, "Bold", C.GOLD_TEXT);
  addRect(root, "Category_Pill", 642, 58, 350, 40, C.WHITE, 20, 2);
  addText(root, "LAYANAN EKSKLUSIF · 5 HARI JADI", 666, 69, 15, "Bold", C.NAVY);
  addRect(root, "Header_Divider", 88, 122, 904, 1.5, C.LINE);

  // Open Headline on Cream Canvas (y = 156..400)
  addText(root, "Website Toko Resmi.", 88, 156, 76, "Black", C.NAVY);
  addText(root, "5 Hari", 88, 250, 76, "Black", C.NAVY);
  addRect(root, "Highlight_Pill_Yellow", 336, 246, 656, 88, C.YELLOW, 18, 2.5, true);
  addText(root, "Langsung Tayang.", 360, 252, 70, "Black", C.INK);
  addText(root, "Desain kustom sekelas brand nasional. Terima beres tanpa pusing koding.", 88, 358, 22, "Medium", C.SLATE);

  // 3 Clean Editorial Value Pillars (x = 88..504, y = 436..1056)
  const pillars = [
    ["01", "Kecepatan Bintang Lima", "LCP <1.2s · PageSpeed 98+", "Bukan template lemot. Skor PageSpeed 98+ bikin klik iklan Meta Ads langsung kebuka."],
    ["02", "Mesin Tracking Meta Ads", "Pixel + Server CAPI Aktif", "Rekam data pembeli akurat 100% agar algoritma iklan otomatis cari pembeli."],
    ["03", "Auto-WA Checkout Kilat", "1-Klik Langsung ke CS", "Katalog produk rapi & tombol WA melayang otomatis di HP pembeli, siap terima order."]
  ];

  pillars.forEach(([num, title, tag, desc], idx) => {
    const py = 452 + idx * 208;
    addRect(root, "Num_" + num, 88, py, 48, 48, idx === 0 ? C.NAVY : C.WHITE, 12, 2);
    addText(root, num, 100, py + 12, 18, "Black", idx === 0 ? C.YELLOW : C.NAVY);
    addText(root, title, 152, py - 2, 26, "Extra Bold", C.NAVY);
    addText(root, tag, 152, py + 32, 15, "Bold", C.CRIMSON);
    addText(root, desc, 88, py + 68, 18, "Medium", C.SLATE, 416);
    if (idx < 2) addRect(root, "Divider_" + idx, 88, py + 184, 416, 1.5, C.LINE);
  });

  // Right Column: Manual Image Drop-Zone (x = 544..992, y = 436..1056, w = 448, h = 620)
  const dropZone = figma.createFrame();
  dropZone.name = "02_HERO_IMAGE_DROP_ZONE";
  dropZone.x = 544; dropZone.y = 436;
  dropZone.resize(448, 620);
  dropZone.cornerRadius = 28;
  dropZone.fills = [{ type: 'SOLID', color: C.WHITE }];
  dropZone.strokes = [{ type: 'SOLID', color: C.INK }];
  dropZone.strokeWeight = 2.5;
  dropZone.effects = hardShadow(6, 6);
  dropZone.clipsContent = true;
  root.appendChild(dropZone);

  const sunHalo = figma.createEllipse();
  sunHalo.name = "Sun_Accent_Halo";
  sunHalo.x = 74; sunHalo.y = 114;
  sunHalo.resize(300, 300);
  sunHalo.fills = [{ type: 'SOLID', color: C.YELLOW }];
  sunHalo.strokes = [{ type: 'SOLID', color: C.INK }];
  sunHalo.strokeWeight = 2;
  dropZone.appendChild(sunHalo);

  addText(dropZone, "DROP CUTOUT PHOTO HERE", 96, 240, 18, "Black", C.NAVY);
  addRect(dropZone, "Proof_Bar_Bottom", 36, 536, 376, 56, C.NAVY, 16);
  addText(dropZone, "LCP 0.8s · PageSpeed 99", 60, 553, 16, "Bold", C.WHITE);

  // Sleek Single-Row Conversion Bar (x = 88..992, y = 1136..1296, w = 904, h = 160)
  addRect(root, "03_CONVERSION_BAR", 88, 1136, 904, 160, C.NAVY, 24, 2.5, true);
  addText(root, "INVESTASI TERIMA BERES · GARANSI 5 HARI", 128, 1166, 15, "Bold", C.YELLOW);
  addText(root, "Mulai Rp 1.500.000", 128, 1196, 42, "Black", C.WHITE);
  addText(root, "Sekali bayar · Gratis domain .COM & SSL", 128, 1250, 15, "Medium", C.CREAM);

  addRect(root, "CTA_WA_Button", 530, 1173, 430, 86, C.EMERALD, 16, 2.5, true);
  addText(root, "Konsultasi Gratis →", 622, 1190, 24, "Black", C.WHITE);
  addText(root, "WA: 0851-9659-8881", 654, 1224, 16, "Bold", C.WHITE);

  // Footer (y = 1340..1390)
```

## ✅ 9. Self-Critique Checklist Sebelum Selesai (Mandatory Vision QA)

1. **Apakah kanvas terlihat lega (`58%–65%` background `#F7F4EC` terbuka)?** Jika masih ada lebih dari 4 kotak ber-border di satu poster, hapus kotaknya dan ganti dengan garis pemisah tipis `1.5px #DAD4C6`!
2. **Apakah semua elemen rata di `x = 88` dan `x = 992` (`w = 904px`)?** Cek koordinat `x` dan `x + width` setiap frame utama.
3. **Apakah ada kalimat yang terpotong di baris ke-2?** Pastikan setiap deskripsi poin selesai utuh dengan tanda titik `.` di akhir kalimat.
4. **Apakah garis coret harga (*strikethrough*) tepat membelah tengah angka harga lama?** Pastikan `y_line = y_text + (font_size * 0.52)`.
5. **Apakah `02_HERO_IMAGE_DROP_ZONE` disiapkan dengan `clipsContent = true`?** Pastikan brief foto AI disertakan di chat agar user siap pasang foto cutout.
