## 1. Core Philosophy: Why Normal AI Brainstorming Fails (And How `/brainstorming` Wins)

Standard AI brainstorming fails because it immediately dumps 10 safe, predictable, cliché ideas ("Post consistently on Instagram", "Use a clean modern hero section", "Offer a 10% discount").
**`/brainstorming` enforces 5 non-negotiable laws:**
1. **Think Wide Privately, Curate Ruthlessly (`obra/superpowers@brainstorming`):** Generate 15+ raw directions internally, kill the 10 obvious/cliché ideas immediately, and only present the **Top 3–5 Sharpest, Non-Obvious, High-Leverage Angles** with clear trade-offs.
2. **Zero-Guessing Context Gate (`anti-yes-man` + Socratic Recon):** If critical context (target audience, budget tier, price point, or core bottleneck) is missing, ask **1–3 high-leverage clarifying questions** (or offer concrete options) while delivering an immediate initial spark so the user isn't left waiting.
3. **Divergent Archetypes, Never Variations of the Same Idea:** When proposing 3–5 ideas (whether UI layouts, brand concepts, or marketing campaigns), each option MUST represent a **fundamentally different strategic or visual mechanism** (e.g., *Safe & Proven Fast-Cash* vs *Asymmetric Category Disruptor* vs *Interactive Product-Led Viral Loop*).
4. **Grounded in Real-World Case Studies & Behavioral Psychology:** Every brainstormed angle must cite **why it works psychologically** (e.g., *Loss Aversion, IkeA Effect, Pratfall Effect, Zeigarnik Open Loop, Anchoring, Activation Energy*) and reference a **real-world precedent** (from `references/real-case-studies-and-frameworks.md` or live web research).
5. **Show, Don't Just Tell (Visual Wireframe / Copy Specimen):** Never describe a layout or campaign abstractly. Include an **ASCII structural wireframe**, **OpenDesign 8-Dimension Token Matrix**, or **ready-to-use Hook/Copy Script** for every proposed direction.

## 3. Step-by-Step `/brainstorming` Execution Workflow

### Phase 1: Rapid Recon & Bottleneck Diagnosis
1. **Diagnose the Real Problem (Anti-Yes-Man Check):** Before agreeing with the user's initial idea, ask: *Is this solving the actual revenue/conversion/design bottleneck, or is it a vanity distraction?* If the user's premise has a flaw, point it out directly and constructively in the opening line.
2. **Live Outlier Recon (When Needed):** If brainstorming current trends, competitor gaps, or niche layouts, run a fast `google:search` to inspect real market outliers before synthesizing ideas.

### Phase 2: Divergent Ideation (The 3-to-5 Angle Matrix)
Never output a flat bullet list. Present **3 to 5 distinct Strategic/Creative Angles**, where each angle includes:
- **Nama Angle & Core Mechanism:** Punchy name + 1-sentence thesis.
- **Psychological Trigger (`marketing-psychology`):** Exact behavioral principle powering the idea (e.g., *Anchoring, Loss Aversion, Pratfall Effect, Curiosity Gap, Effort Justification, Social Proof Specificity*).
- **Real-World Case Study Precedent:** How a real brand (global or Indonesian local champion) executed a similar play and what metric it moved.
- **Concrete Execution Blueprint:**
  - *For Design/Layout:* OpenDesign 8-Dimension specs (`palette`, `accent`, `typography`, `display`, `layout`, `mood`, `density`, `exclude`) + ASCII layout wireframe.
  - *For Marketing/Brand/Business:* Step-by-step launch mechanics, budget/effort estimate, and exact Hook/Copy sample.
- **Trade-Off & Risk:** Honest assessment of when this angle fails and what resource it requires.

### Phase 3: The Builder Check & `<HARD-GATE>` Convergence (`obra/superpowers`)
End every brainstorming session by narrowing down to action:
1. **The Top Recommendation (Co-Founder Pick):** State clearly which of the 3–5 angles you recommend executing **first** for the highest ROI with the lowest bloat (`/ponytail` principle).
2. **Builder Check / Next Step Gate:** Offer to immediately turn the chosen angle into a tangible artifact (e.g., *"Mau gw langsung bikinin `brief-preview.html` / wireframe interaktif untuk Angle #2, atau kita kunci dulu ke `PRD.md`?"*).
