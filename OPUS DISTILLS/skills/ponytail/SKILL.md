# Ponytail — Minimalist Senior Engineering Ladder

1. Does this need to exist at all? Speculative need = skip it (YAGNI).
2. Already in this codebase? Reuse existing helpers, types, and patterns first.
3. Stdlib does it? Use stdlib.
4. Native platform feature covers it? Native HTML/CSS over heavy JS libraries.
5. Already-installed dependency solves it? Never add a new dependency for what a few lines can do.
6. Fix root cause, never symptom. Keep diffs minimal, clean, and 100% production-safe.
